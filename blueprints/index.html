📨 Telegram Lead Finder

Reads public Telegram groups and catches people asking for your service. Free keywords throw out the noise, a cheap AI picks the real requests, and each lead lands on your phone. Under $10 a month in AI.

Download PDF Link to this tool
Rebuild it: paste these into Claude or ChatGPT, one at a time

Paste these into your AI chat one at a time. Test after each step before you go on.

1Plan it first+ 
I am not a coder. I want to build a small Python program that reads public Telegram groups and finds people asking for a service in my niche: [YOUR NICHE]. It should: 1) filter messages by keywords, 2) send only matching messages to a cheap AI model to decide if it is a real request, 3) send real requests to me through a Telegram bot. Explain the plan in plain English and list the accounts I need. No code yet.
2Connect to Telegram and just print messages+ 
Write a short Python script with the Telethon library. It logs in with my spare Telegram account (API ID and hash read from a .env file) and prints each new message from my groups with the group name and the sender's @username. Tell me how to install Python and run it the first time.
3Build the keyword list+ 
My niche is [YOUR NICHE] in [YOUR CITY]. Write 500 keywords and short phrases people use when they ask for this service in a group chat. Include trade names, the jobs themselves, and ways of asking ("need a…", "who knows a good…", "recommend a…"). Add common versions in [LANGUAGES YOUR COMMUNITY USES]. Then add 20 "blocker" phrases for job ads and spam. Save them as keywords.txt and blockers.txt, one per line.
4Add the free keyword filter+ 
Load keywords.txt and blockers.txt. Skip a message if it has no keyword, has a blocker, or is the same text already seen in another group today. Print "KEYWORD HIT: <keyword>" for the rest. Count messages seen and keyword hits.
5Let a cheap AI judge each hit+ 
For each keyword hit, call the cheapest model of [AI PROVIDER] with this job: "Is this a real person asking to hire a [YOUR NICHE] service? Answer only JSON: {"is_lead": true/false, "reason": "one short sentence"}." Adverts, job posts, stories about past work, and requests for other services are NOT leads. Read the API key from .env. Wait 3 seconds between calls and retry if the API is busy. Log the cost of each call.
6Send leads to your phone+ 
Create the alert step. I made a bot with @BotFather and have its token and my chat ID. When the AI says is_lead is true, send me a bot message with: the group name, the original message, the sender's @handle, and the AI's reason. Add a last line: "Tip: reply with a 30-second video circle." Do not include names, phone numbers or anything else about the person.
7Keep it running 24/7+ 
Help me run this nonstop. Option A: a $5 a month Linux server with a service that restarts it if it crashes. Option B: my laptop, kept awake. Give exact steps for both, plus how to check the logs and the daily AI cost.

I'm not a programmer. Help me build a simple CRM web app for a small sales team with Next.js and Supabase. Explain each step in plain words. First, set up the project and a login page with email and password.
2Make the client card+ 
Add a client card. Each client has: name, phone, WhatsApp, email, budget, what they want, favourite areas, birthday, ID expiry date and notes. Show it all on one phone-friendly screen with big "Call" and "WhatsApp" buttons. Show a red warning if the ID expires within 60 days.

📍 Google Maps Scraper

A Chrome extension. Search Google Maps, click one button, and it scrolls and grabs every business into a spreadsheet. Sort by website and the businesses with no website float to the top.

Rebuild it: paste these into Claude or ChatGPT, one at a time

Paste these into your AI chat one at a time. Test after each step before you go on.

1Plan it first+ 
I am not a coder. I want a simple Chrome extension (Manifest V3) that works on Google Maps search results. When I click a button in the popup, it should scroll the results list on the left, read each business card, and let me download the results as a CSV file. Before writing code, explain in plain English which files we need and what each one does. Keep it as small as possible.
2Make the skeleton+ 
Write the full code for every file: manifest.json, popup.html, popup.js and content.js. The popup should have a big "Start" button, a counter that says how many businesses were found, and an "Export CSV" button. For now the Start button can just show "Hello from Google Maps" in the counter. Then tell me how to load it in Chrome with Developer mode and "Load unpacked".
3Read the cards+ 
Now make content.js read the business cards that are visible in the Google Maps results list. For each card, get: name, category, rating, review count, address, phone, website link and the Google Maps link. Skip duplicates. Send the list back to the popup and show the count. If you are not sure which page elements to use, tell me how to right-click and "Inspect" a card so I can paste you the HTML.
4Auto-scroll+ 
Add auto-scroll. After Start, scroll the results list down a bit every second, read the new cards each time, and stop when the list stops growing for about 5 tries. Update the counter as it goes. Add a Stop button that halts it.
5Export the spreadsheet+ 
Make "Export CSV" download a file named leads-YYYY-MM-DD.csv with one row per business and these columns: Name, Category, Address, Phone, Rating, Review Count, Website, Google Maps URL. Wrap every cell in quotes so commas in addresses do not break the file.
6Keep results safe+ 
Save the results in chrome.storage.local, so they are still there if I close the popup. Add a "Clear" button to start fresh before a new search. Let the scrape keep running if I switch to another tab.
7Add a simple log+ 
Add a second tab in the popup called "Logs". Write short plain-English lines there: "Started", "Found 40 so far", "Reached the end", and any error. When something breaks, I will copy the log and paste it to you.
8Fix it when it breaks+ 
The extension stopped finding businesses. Here is the log and the HTML of one result card (from right-click, Inspect, Copy outerHTML). Find what changed and give me the full updated content.js. Use a few backup ways to find the cards so one small change on the page does not break it.

Make a page called "New offer". On the left: a search box and the list of services grouped by category. Each service has a checkbox and a quantity. On the right: a cart that shows each picked service, its price, the tax, and the total. Update the total as soon as I tick or untick something.

1Start the project+ 
I'm not a programmer. Help me build a small invoice tracker with Next.js and Supabase, explained in plain words. First, create an "invoices" table: money in or out, date, company, amount, VAT, category, paid (yes or no), file link.
2Connect Google Drive+ 
Connect two Google Drive folders, "Money In" and "Money Out", with a Google service account. Walk me through creating it and sharing the folders. Then list any new PDFs we have not saved yet. Keep the key out of the code.

🧑‍💼 HR Tool

Leave, sick days and letters handled with two buttons. Every employee gets their own page, HR approves in chat, and employment letters come out as signed, stamped PDFs.

Download PDF Link to this tool
Rebuild it: paste these into Claude or ChatGPT, one at a time

Paste these one at a time. Test each step with two fake employees.

1Start the project+ 
I'm not a programmer. Help me build a simple HR tool with Next.js and Supabase, and explain each step in plain words. Create tables for: employees (name, email, job title, start date, yearly leave days, monthly salary), leave requests (type, start, end, days, status, note file), public holidays (date, name), and document requests (type, status, file).
2Count days the right way+ 
Write one function that counts working days between two dates. Skip weekends and any date in the public holidays table. Then work out each employee's days left this year: yearly days minus approved days. Add a few tests with tricky dates, like a request that crosses a public holiday.
3Build the employee page+ 
Make a "My Hub" page for the logged-in employee. Show three cards: days left, days taken, and pending. Below, show a month calendar with public holidays marked, a list of their requests with status, and a small table of salary by month. It must look good on a phone.
4Let people ask for time off and log sick days+ 
Add two forms on My Hub. "Request time off": type, from, to, reason. Save it as "pending". "Log sick leave": from, to, note. If the sick days are more than 2 working days, show a file upload for a doctor's note and don't allow saving without it. Sick leave is saved as approved right away.
5Send requests to the HR lead in a chat+ 
Create a Telegram bot and connect it with a webhook. When someone requests time off, post a message in the HR group: name, dates, number of days, days left after this, and two buttons, "Approve" and "Deny". Only people marked as HR in the database may press them. Keep the bot token out of the code.
6Handle the button press+ 
When HR presses Approve or Deny, update the request status, edit the chat message to show who decided and when, remove the buttons, and send the employee a private message with the result. Make sure a second tap can't decide the same request twice.
7Make signed employment letters+ 
Add "Request employment letter" on My Hub, with an optional "addressed to" field. It posts to the HR chat with Approve / Deny. On Approve, create a PDF on our letterhead with the employee's name, job title, start date and salary, add our signature and stamp images, save it, and send it to the employee in the chat and by email.
8One place for everything+ 
Make an HR dashboard (HR only) with tabs: Team (everyone with days left), Leave (all requests and a team calendar), Documents (company policies plus every letter request, with Approve / Deny buttons), and Public holidays (add or remove dates for the year).

💬 Knowledge Chat

Paste a client email and get the right answer with sources. It knows your products, prices and notes, checks government sites for rule changes, and says so when it doesn't know.

Download PDF Link to this tool
Rebuild it: paste these into Claude or ChatGPT, one at a time

Paste these prompts into Claude, ChatGPT or Claude Code one at a time. Test after each step before you go on.

1Plan it+ 
I want an internal "knowledge chat" for my sales team. We paste a client's email and it drafts a reply using ONLY our own product files. I am not a coder. Plan a simple web app: pages, where the data lives, which AI to use, and the monthly cost. Ask me 5 questions first.
2Build the chat screen+ 
Build version 1 as a Next.js web app. One page: a big "Client question" box, a "Draft reply" button and a reply area with a Copy button. Use fake answers for now. Tell me exactly how to run it on my computer.
3Load your knowledge+ 
Add a "Knowledge base" page to upload PDF, Word, Excel and text files. Split each file into small chunks and save them in a searchable database (Supabase is fine). Let the AI sort each file into one of these categories: [your list]. Show a table of files and their category.
4Connect the AI with three hard rules+ 
Make "Draft reply" real. Find the 10 chunks that best match the question and ask the AI for a short, friendly reply. Add these hard rules:
1) Answer only from the chunks provided.
2) For every product or price, name the source it came from.
3) If the chunks don't answer the question, start the reply with "I don't know" and explain what is missing. Never guess. Show the sources used under the reply.
5Test that it refuses to guess+ 
Write 10 test questions: 5 our files can answer and 5 they can't. The 5 it can't answer must start with "I don't know". Give me one button to run all 10 and show pass or fail.
6Add government sites+ 
Add a "Government sites" page where I paste up to 5 web addresses. Once a day, check each page. If it changed, ask the AI for a 2-sentence summary, save it as a "rule update" and use it in matching replies, with a link to the source.
7Show the cost of each answer+ 
Log what every reply cost in dollars. Show "This answer cost $0.xx" under it. Add a "Usage" page with the monthly total and the average cost per answer.
8Lock it down and put it online+ 
Add a login so only my team can use it. Then walk me through putting it online on Vercel. Keep API keys in environment variables, never in the code.

🎬 AI Video Editor

Drop in raw footage, get a finished edit back. It cuts the pauses and bad takes, adds captions and motion graphics, and turns every note you give it into a rule. It edited the video you just watched.

Download PDF Link to this tool
Rebuild it: paste these into Claude or ChatGPT, one at a time

Open Claude Code in an empty folder, for example `my-video-editor`. Paste these one at a time.

1Install skills and tools+ 
I want you to become my video editor. I am not technical. Before any editing, set this folder up for video work: install ffmpeg, a free Whisper-style transcriber that gives word-level timestamps, and a Remotion project for motion graphics. Also look for ready-made skills or guides that make you better at Remotion and video editing, and add them. Check each one works.
2Study creators you love+ 
Here are links to 5 videos whose editing style I love: [paste links]. Study each one. Write a file called style-notes.md with what they do: caption style and size, where text sits, how often the shot changes, zooms, transitions, sound effects, music, colours and fonts. End with a short list of "do this" and "never do this".
3Let it interview you+ 
Now interview me before you edit anything. Ask about me, my audience, this video, the style I want, the length, the platform, and anything else you should know. Ask one question at a time, as multiple choice with 3-4 options, plus "other" so I can type my own. Save my answers in brief.md.
4Ask what you missed+ 
Is there anything I didn't ask you to do, or anything you should ask me, to get the best result? List it, ask me, and add the answers to brief.md.
5Transcribe and cut+ 
My raw clips are in the folder raw/. Transcribe them with word timestamps. My script is in script.txt, one sentence per line. For each sentence, find my best complete take (usually the last one). Cut out pauses longer than a quarter second, filler words and false starts. Join the pieces with ffmpeg into one clean talking video. Never let two pieces overlap, or words will repeat. Show me a list of what you kept and what you cut.
6Check the cut+ 
Transcribe the clean video again and compare it word by word with script.txt. List any missing, repeated or extra words. Fix them, then check again.
7Add graphics and render+ 
Using Remotion, add captions and motion graphics to the clean video. Follow style-notes.md and brief.md. Tie every graphic to the word it belongs to. Keep text away from the edges where the app buttons sit. Save a few still frames so I can check them, then render the full video to final.mp4.
8Turn feedback into rules+ 
Here is my feedback on this edit: [your notes]. Fix it. Then save each note as a short rule in a folder called rules/, one file per rule, with the date. Keep an index file that lists every rule in one line. Read all the rules before every future edit.
